# 研究臂计数

study_id唯一，每研究内treatment_id唯一。responders是预设观察窗内达标人数，total为固定分母，当前资料不允许0或全响应端点。不同研究的同一treatment_id指同一干预；同一多臂研究所有臂属于同一个随机分配研究，不能假定派生比较独立。

tau_grid是效应对数尺度上的标准差搜索域，严格升序、非负。solver.tolerance用于数值求解残差与同分容差的公开记录；重选参考是线性坐标变换，不改变实际比较含义。对比方向统一为前一个治疗减后一个治疗。normal_z由调用者选择，不自动赋予未声明的区间含义。

已有domain只给逐臂对数优势和方差，不建网络、不求关联GLS。
