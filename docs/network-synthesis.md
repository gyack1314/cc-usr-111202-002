# 关联证据网络合成:方法与结果

`research_data.nma`在逐臂摘要之上增加网络合成:同一多臂研究的派生比较共享对照臂,其抽样相关必须进入协方差,不能再把三臂研究拆成三条独立比较(那会让共享对照臂的研究近乎双倍计权)。所有数值来自合成资料,不含真实药品疗效结论。

## 模型与计算口径

- 每研究以treatment_id最小臂为局部参考,构造其余臂减参考臂的log-odds;臂抽样方差`1/r+1/(n-r)`;比较向量协方差对角为本臂加参考臂方差、非对角为参考臂方差;研究间独立;多臂相关矩阵保持完整,不对角化。
- 每个连通分量单独拟合一致性相对效应,分量内最小treatment_id为零参考;跨分量比较不可识别,如实列出。
- 异质性:tau取自资料给定的非负升序网格,每研究附加协方差对角tau²、非对角tau²/2。每个tau用完整协方差GLS求参数与条件协方差,最小化REML目标`log|V|+log|X^T V^-1 X|+加权残差平方`(省略与tau无关常数),同分在`solver.tolerance`内容差取较小tau;报告网格最优而非连续最优。残差自由度为零时仅给tau=0条件拟合,并标记异质性不可识别。
- 数值:Cholesky分解求解,信息矩阵经Jacobi特征值检测秩与病态(条件数随结果公开),不使用裸矩阵求逆或岭项掩盖断网。
- 对比方向统一为排序在前治疗减排序在后治疗;区间为正态近似(`normal_z`取自资料),以选定tau为条件,**未计入tau选择不确定性**。

复现:

```sh
python -m research_data.cli synthesize data/normal.json
```

输出含方法记录、各分量tau网格轨迹、方向一致的两两比较、逐研究残差与权重,以及逐研究删除敏感性(重构图、重选tau)。

## data/disconnected.json(sha256前16位 b8d2f51d6a3e8569)

两个连通分量:{A,B,C,D}结果与normal.json完全一致(相同研究),{E,F}仅含单研究separate,残差自由度0,强制tau=0并标记异质性不可识别;E-F估计-0.7673±0.7296。跨分量8对比较(A/B/C/D对E/F)全部不可识别,不给出估计。删除separate后E-F对比消失;删除bridge后D的三个对比消失。

## data/saturated-three-arm.json(sha256前16位 53de1a698fcafb77)

单三臂研究,2个比较、2个参数,残差自由度0:仅给tau=0条件拟合,异质性不可识别。A-B与A-C估计均为-ln(7/3)≈-0.8473,B-C估计恰为0、标准误√(0.1+1/9)≈0.4595,与手算一致;残差全零,研究权重份额为1。

## 验证

`tests/test_nma.py`固定了以下性质:饱和三臂与E-F分量的手算锚点;normal.json每个网格tau的REML目标、选定参数与条件协方差,对照测试内独立实现的完整协方差装配+暴力求逆;更换臂顺序、研究顺序与局部参考(线性坐标变换)不改变可识别治疗对结果与tau选择;逐研究杠杆之和等于参数数;端点计数与非法tau网格被拒绝。
